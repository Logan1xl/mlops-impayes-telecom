Ça marche vraiment sans internet ?

Oui. La page et le modèle sont embarqués : l'inférence s'exécute en JavaScript sur le poste. Idéal pour les régions à faible connectivité — et pour les démonstrations terrain.

Nos données partent-elles quelque part ?

Non. Le mode autonome n'émet aucun appel réseau. En mode connecté, les requêtes partent uniquement vers l'API de votre organisation, avec traçabilité complète (request_id → modèle → commit → données).

Peut-on ré-entraîner sur nos données ?

Oui. Tout le pipeline DVC/MLflow est inclus : téléchargement, contrat de données, 3 algorithmes comparés, quality gate, promotion humaine. Votre modèle reste votre actif.

Et si le modèle se dégrade ?

La surveillance (PSI/KS quotidienne, F1 sur impayés constatés) déclenche une alerte, puis un réentraînement contrôlé — jamais un remplacement aveugle. Rollback immédiat vers la version précédente.

    Importance par permutation (test) :

    Honnêteté méthodologique. Le sujet évoque un F1 de 0,88 sur un modèle en poste — le vrai jeu nigérian est beaucoup plus dur : les classes « medium » (rappel 0,087) concentrent la confusion. La réplique synthétique utilisée pour développer la chaîne donnait 0,649. Les chiffres réels sont ceux ci-dessus ; toute amélioration (calibration, features métier, coût asymétrique) est un prolongement identifié, pas un masquage.
